Hasar AI 2.3’ü yeniden kontrol ettik ve 30 araştırma temelli beceri öğrendik. 20 tanesi bugün uygulandı, 2 tanesi ölçüldü ama kazanç göstermediği için yayınlanmadı, 8 tanesi planlandı (çoğu GPU gerektiriyor). Sonuçlar: karşılaştırma → 4) Denetim.We re-checked Hasar AI 2.3 and learned 30 research-backed skills. 20 were applied today, 2 were measured but not shipped because they showed no gain, and 8 are planned (most need a GPU). Results: comparison → 4) Audit.

Denetimde ne bulunduWhat the audit found

  • “Kırık / eksik parça” gerçek fotoğraflarda ~2’de 1 doğru (DrBimmer’da ~%97). Artık “olası” etiketi ve toplama dahil olmayan koşullu maliyet.“Broken / missing part” is right ~1 in 2 times on real-world photos (~97% on DrBimmer). Now labelled “possible”, with a conditional cost outside the total.
  • 186 sentetik fotoğrafın katkısı ≈ 0; 2.3’teki kazanç gerçek fotoğraflardan.The 186 synthetic photos contribute ≈ 0; the 2.3 gain comes from the real photos.
  • Türkiye tampon fiyatları piyasanın 1,7–3,1 katıydı; maliyet modeli 1.1 ile alt sınır bağımsız servis teklifine bağlandı.Türkiye bumper prices were 1.7–3.1× the market; cost model 1.1 ties the low end to independent-shop quotes.
  • API eski TL formülünü kullanıyordu; API 1.6.2 sitedeki ülke bazlı modelin aynısını döndürüyor.The API still used the old TRY formula; API 1.6.2 returns the same per-country model as the site.
  • Galeri sonuçları 2.0.0’dan kalmıştı; 2.3.1 ile yenilendi.The gallery results were still from 2.0.0; regenerated with 2.3.1.

    📄 Recht et al. 2019 — Do ImageNet classifiers generalize to ImageNet? (new test sets: 11–14 pt drops) ↗

  2. 2Dağılım dışı (OOD) test setiOut-of-distribution test setUygulandıApplied

    📄 Geirhos et al. 2020 — Shortcut learning in deep neural networks (o.o.d. tests should be the rule) ↗

    📄 Oakden-Rayner et al. 2019 — Hidden stratification (error auditing finds failures that metrics hide) ↗

  4. 4Ayar / test ayrımı (sızıntı yok)Tune / test separation (no leakage)UygulandıApplied
